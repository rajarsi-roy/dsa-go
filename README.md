# 🚀 DSA in Go

A curated, well-documented collection of classic Data Structures and Algorithms implemented entirely in Go (Golang). 

This repository serves as a personal learning journey and a quick reference guide for writing clean, idiomatic, and efficient algorithmic code in Go. Whether you're preparing for technical interviews, brushing up on computer science fundamentals, or just exploring Go's capabilities, you'll find useful patterns here.

## 🧠 What's Inside

- **Data Structures:** Arrays, Linked Lists, Stacks, Queues, Hash Tables, Trees (BST, AVL, Trie), and Graphs.
- **Algorithms:** Sorting (Merge, Quick, Heap), Searching (Binary, BFS, DFS), and Dynamic Programming.
- **Problem Solving:** Common patterns and solutions to popular algorithmic problems (e.g., LeetCode/HackerRank).

## 🛠 Features

- **Idiomatic Go:** Code written leveraging Go's strengths, including pointers, slices, and interfaces.
- **Tested:** Each implementation comes with Go tests (`_test.go`) to verify correctness and edge cases.
- **Documented:** Clear comments explaining time and space complexities (Big O).
